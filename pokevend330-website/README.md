# PokeVend 330 Website — Stage 3

This build separates audiences:

- `/` customer-facing homepage
- `/partners/` business-owner placement page

## Install
Copy these files into the root of your local `pokevend330-website` repository, replacing the older Stage 1 files.

```powershell
git add .
git commit -m "Build customer homepage and partner page"
git push origin main
```

GitHub Pages will redeploy automatically.

Once your custom domain is connected, the business-owner URL will be `https://pokevend330.com/partners/`.
