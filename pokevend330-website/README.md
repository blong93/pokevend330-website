# PokeVend 330 Website

Static HTML/CSS/JavaScript website for PokeVend 330.

## Run locally
Open `index.html` directly or use the VS Code Live Server extension.

## Git workflow
```bash
git add .
git commit -m "Build Stage 1 homepage"
git push origin main
```

## Deploy with GitHub Pages
1. Push this project to your `pokevend330-website` repository.
2. On GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save.

## Custom domain
After GitHub Pages is live, add `pokevend330.com` under **Settings → Pages → Custom domain** and follow GitHub's DNS instructions.
